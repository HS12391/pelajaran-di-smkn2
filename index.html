FAQ

Pertanyaan yang sering ditanyakan.

Apakah saya bisa upgrade paket kapan saja?

Bisa. Upgrade resource (CPU, RAM, storage) dilakukan langsung dari dashboard tanpa perlu migrasi data atau downtime berarti.

Apakah ada garansi uang kembali?

Ya, semua paket VPS dan Cloud Server memiliki garansi uang kembali 7 hari jika layanan tidak sesuai kebutuhan Anda.

Bagaimana proses migrasi dari hosting lain?

Tim teknis kami membantu proses migrasi data, database, dan konfigurasi secara gratis untuk pelanggan baru, biasanya selesai dalam 1×24 jam.

Apakah backup harian termasuk dalam semua paket?

Backup harian otomatis termasuk pada paket Bisnis ke atas. Paket Starter dapat menambahkan Managed Backup sebagai add-on.

Metode pembayaran apa saja yang didukung?

Transfer bank, kartu kredit/debit, virtual account, dan QRIS — pembayaran tahunan juga bisa dicicil untuk paket Enterprise.

Apakah ada kontrak jangka panjang?

Tidak ada kontrak wajib. Semua paket bulanan bisa dihentikan kapan saja tanpa biaya penalti.
